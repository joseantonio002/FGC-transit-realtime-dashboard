# ANGENTS.md

This repository builds a transit performance dashboard using **GTFS Static** (scheduled service) plus **GTFS Realtime** (observed service) to compute **delay, cancellations, and completion** for bus trips and show a real time map for the vehicles.

For this project use python

## Code style

- Use python type hints ALWAYS
- Use two spaces for identation
- Add docstring comments at the beggining of each function
- Use relative routes
